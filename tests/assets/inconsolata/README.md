# Inconsolatazi4 Test Fonts

Unmodified static OpenType/CFF fonts from CTAN's `inconsolata` package, version
1.121. These fixtures verify the exact family name, Regular/Bold-only style
catalogue, download validation, and private-cache installation without network
access. They are not installed system-wide or bundled with the application.

- Package: https://ctan.org/pkg/inconsolata
- Upstream notice: https://mirrors.ctan.org/fonts/inconsolata/README
- Regular: https://mirrors.ctan.org/fonts/inconsolata/opentype/Inconsolatazi4-Regular.otf
- Bold: https://mirrors.ctan.org/fonts/inconsolata/opentype/Inconsolatazi4-Bold.otf
